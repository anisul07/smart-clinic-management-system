# Smart Clinic Management System — User Stories

## Doctor

**As a Doctor, I want to:**
- Log in securely.
- View my appointments.
- View patient details.
- Manage my availability.
- Access prescription-related information.

**So that:** I can manage my clinical activities efficiently.

---

## Patient

**As a Patient, I want to:**
- Log in securely.
- Search for doctors.
- View doctor availability.
- Book appointments.
- View my appointments.

**So that:** I can manage my healthcare appointments.

---

## Admin

**As an Admin, I want to:**
- Log in securely.
- Manage doctors.
- Manage patients.
- Manage the Smart Clinic Management System.

**So that:** The clinic's operations can be administered efficiently.
